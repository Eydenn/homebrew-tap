# Eydenn's Homebrew tap

```bash
brew install eydenn/tap/loomy
```

Or tap once, then use the short name:

```bash
brew tap eydenn/tap
brew install loomy
```

| Formula | Description |
|---|---|
| `loomy` | Your AI development team, orchestrated: Claude Code and Codex on your projects, each request routed to the right model for the least cost, cross reviews, official skills, shared memory and live tracking. [github.com/Eydenn/loomy](https://github.com/Eydenn/loomy) |

Update with `brew upgrade loomy` (or `loomy update`).
